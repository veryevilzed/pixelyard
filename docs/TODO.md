## Известные ограничения

- Папки слоёв — один уровень (вложенные папки PSD сворачиваются в имена слоёв); у папки нет режима
  наложения «как целое».
- В панели слоёв нельзя выделить несколько слоёв (⇧/⌘) — папка создаётся из одного слоя.
- Сканер снимает всё стекло, область вырезается у нас (медленнее на 600 dpi, зато область точная).
- «Наилучший» упаковщик на 300+ спрайтах — ~0,3–0,4 с на каждое изменение (можно в Web Worker).
- Spine/libGDX: кадры анимаций с полным именем и `index` (`findRegions()` по общему имени не найдёт).
- Открытые `.fnt` хранятся в localStorage с картинками — очень большой шрифт может не сохраниться.

## Идеи

- Выделение нескольких слоёв; вложенные папки; режим наложения папки.
- Перетаскивание спрайтов между папками атласа, миниатюры страниц атласа.
- Сканер: задавать область драйверу, когда станет ясна его система координат (быстрее).
- Мелочи: швы в превью перспективы, `hdiutil create` пишет предупреждение об устаревании.
