## Решения по дизайну

### Атлас как документ
- `Doc.kind: 'image' | 'atlas'`; у атласа поле `atlas: AtlasState` (неизменяемый объект).
- `AtlasState` входит в `Snapshot` истории (`src/core/doc.ts`): undo/redo настроек и свойств
  спрайтов через обычный `doc.change()`.
- `doc.layers` атласа = один заблокированный слой «Атлас» с канвасом **текущей страницы**;
  пересчитывается после каждого изменения (debounce ~120 мс) и после undo/redo — в историю не пишется.
  Так бесплатно работают вкладки, сплит, зум, навигатор, линейки.
- `doc.width/height` = размер текущей страницы; переключатель страниц — `atlasPage` (не в истории).
- В меню: `hasDoc`/`hasLayer` → false для атласов в пунктах, меняющих пиксели
  (Изображение, Слои, Выделение, Фильтр, Нарезка). Для атласа — отдельный пункт меню **«Атлас»**.

```ts
interface AtlasSprite {
  id: string; name: string;
  image: HTMLCanvasElement;          // исходник (неизменяемая ссылка; правка → новый объект)
  scale: number;                     // свой множитель, по умолчанию 1
  trim: 'inherit' | 'on' | 'off';
  extrude: number | null;            // null = общий
  rotate: boolean;                   // разрешено ли вращение (если включено глобально)
  pivotX: number; pivotY: number;    // 0..1, по умолчанию 0.5
}
interface AtlasSettings {            // упаковка
  maxSize; pot; square; spacing; border; extrude; trim;
  allowRotation; algorithm: 'best'|'maxrects'|'shelf'|'grid';
  heuristic: 'short-side'|'long-side'|'area'|'bottom-left'|'contact';
  sort: 'auto'|'name'|'area'|'max-side'|'height'|'width'|'none';
  multipage: boolean;
}
interface AtlasExport {              // выгрузка — хранится в проекте
  name; formatId; imageFormat: 'png'|'webp'|'jpg'; quality;
  scales: { scale: number; suffix: string; enabled: boolean }[];  // 0.5/@0.5x, 1/'', 2/@2x, 4/@4x
  smoothScale; output: 'folder'|'zip';
}
interface AtlasState { sprites: AtlasSprite[]; settings: AtlasSettings; export: AtlasExport }
```

### Упаковщик (`src/core/pack.ts` — переписать)
- `packPages(items, opts): PackResult { pages: PackPage[] }`; старый `pack()` оставить обёрткой
  (`multipage:false`, `maxrects/short-side`) — им пользуются BMFont и диалог «Спрайтшит».
- MaxRects с эвристиками: short-side (BSSF), long-side (BLSF), area (BAF), bottom-left, contact point.
- Полки (`shelf`) — ряды в заданном порядке; **«Алфавитный» = shelf + sort name**.
- Сетка (`grid`) — одинаковые ячейки.
- **«Наилучший»** = перебор всех эвристик × сортировок (auto/area/height/width) + shelf;
  выбирается минимум страниц, затем минимальная площадь.
- Вращение 90°: `allowRotation` глобально + `noRotate` на спрайт. В `PackedFrame`:
  `w,h` — размер **без поворота**, `rotated: boolean`, в атласе занимает `h×w`.
- **Направление поворота зависит от формата**: `rotationDir: 'cw'|'ccw'` при сборке картинки.
- Многостраничность: сначала пытаемся уложить всё на одну страницу минимального размера
  (перебор кандидатов размеров); если не влезает и `multipage` — заполняем страницы `maxSize`,
  остаток на следующую; каждую страницу ужимаем до занятой области (+pot/square).
- extrude на спрайт (`extrude ?? общий`), spacing, border.
- Черновик переписанного файла был готов, но не записан — писать заново по этому описанию.

### Форматы (`src/core/atlasFormats.ts` — доработать)
- `FormatDef` + `rotation: 'cw' | 'ccw' | false` и `multi: 'per-page' | 'single'`.
- Вращение и единицы (проверено по документации/памяти, перепроверить при реализации):
  - TexturePacker JSON Hash/Array (Pixi, Phaser 2): `rotated`, CW, `frame.w/h` без поворота.
  - Phaser 3 multiatlas: CW, **один JSON на все страницы** (`textures[]`) — `multi: 'single'`.
  - Spine / libGDX `.atlas`: `rotate: true` = **CCW**, `size` без поворота, **один файл на все страницы**
    (секции страниц подряд).
  - Starling/Sparrow XML: CW, `width/height` — **как лежит в атласе** (с поворотом); файл на страницу.
  - Cocos2d plist: CW, `frame` без поворота; файл на страницу.
  - CSS — `rotation: false` (вращение принудительно выключить, показать подсказку). CSV — колонка `rotated`.
  - Свои шаблоны: per-page, переменные `{{rotated}}`, `{{page}}`, `{{pageCount}}`; направление CW.
- Имена страниц: `name-0.png`, `name-1.png` … (одна страница — без суффикса).
- В TP JSON при нескольких страницах — `meta.related_multi_packs`.
- Добавить `pivot` в TP JSON (`pivot: {x,y}`) и шаблоны (`{{pivotX}}`, `{{pivotY}}`).

### Выгрузка
- Для каждого включённого масштаба: спрайты масштабируются (`глобальный × sprite.scale`),
  упаковываются заново (раскладка может отличаться — как в TexturePacker), имена с суффиксом:
  `atlas@2x-0.png` / `atlas@2x.json`.
- `imageFormat` png/webp/jpg (+quality); WebP через существующий `encodeCanvas` (в Tauri — Rust).
- Вывод: папка (Tauri) или zip — `writeFiles()` из `src/core/export.ts`.
- **WebP для BMFont**: в `BMFontDialog` добавить выбор формата картинки и запоминание
  (`localStorage pixelyard.bmfont`), расширение в `.fnt`/JSON.

### Файл проекта `.pyard`
- zip (fflate): `project.json` + `sprites/<id>.png` + `sources/<id>.psd` (многослойные исходники).
- `project.json`: `{ format: 'pixelyard', kind: 'atlas', version: 1, name, settings, export, animations, sprites: [{id,name,folder,file,source?,scale,trim,extrude,rotate,pivotX,pivotY,nine}] }`.
- Открытие: `decodeFile` по расширению → атлас-документ; фильтр в `OPEN_FILTERS`.
- Сохранение: ⌘S на атласе → `.pyard`; путь в `doc.path`.
- Tauri: добавить `bundle.fileAssociations` для `.pyard` (двойной клик в Finder).

### Интерфейс
- **Инструмент атласа** (`src/tools/atlasTool.ts`): `effectiveTool()` подменяет любой инструмент,
  кроме «Руки» и «Масштаба», когда активный документ — атлас.
  - клик — выделить; ⇧/⌘+клик — добавить/убрать; рамка — выделить несколько; Esc — снять.
  - двойной клик — **редактировать спрайт** (открыть картинку отдельной вкладкой).
  - Delete — удалить выбранные; стрелки — выбор соседнего (необязательно).
  - Оверлей: рамки кадров (поворот — значок ↻), выделенные — оранжевые, имя при наведении.
- **Панель «Атлас»** справа (вместо «Слоёв», когда активен атлас):
  - список спрайтов (миниатюра, имя, размер, страница), поиск; добавить (файлы, слои/слайсы
    открытого документа, перетаскивание файлов в окно), удалить;
  - **свойства выделенных** (несколько — общие значения, изменение применяется ко всем):
    имя (если один), scale, trim, extrude, вращение, pivot;
  - страницы: переключатель `0 1 2 …`, размер, заполнение %;
  - выгрузка: формат, картинка, масштабы с суффиксами, имя, папка/zip, кнопка «Выгрузить».
- **Панель опций** при активном атласе: алгоритм, эвристика (для MaxRects), сортировка,
  вращение вкл/выкл, макс. размер, pot, квадрат, зазор, отступ, extrude, обрезка, несколько страниц.
- **Редактирование спрайта**: двойной клик → новый `Doc` (image) с `link: { atlasDocId, spriteId }`.
  Подписка в `App.tsx`: при изменении `doc.rev` связанного документа — композит → новый
  `image` спрайта (без записи в историю атласа) → перепаковка (debounce). Закрытие вкладки
  связь не ломает. В заголовке вкладки — значок связи.
- Создание: «Файл → Новый атлас…», «Атлас → Новый из картинок…», в диалоге «Спрайтшит» —
  кнопка «Открыть как проект атласа».
