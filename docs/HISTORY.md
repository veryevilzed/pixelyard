## 0.1.1 — первый выпуск (30 октября)

**Задача пользователя:** настольный редактор для подготовки игровых и UI-ресурсов на macOS: подправить
картинку, но главное — нарезать, выделить, экспортировать слои и слайсы по одному файлу; инструменты
слева, «смесь Photoshop, Pixelmator и GIMP». Стек выбран Tauri 2 + React + TypeScript + Canvas 2D.

- **Документ и история:** слои неизменяемы по свойствам, пиксели правятся через `pixelEdit` с патчами
  ImageData; структурные изменения — снимками (`doc.change`).
- **Рисование:** кисть (сглаживание, нажим), карандаш (pixel-perfect), ластик, заливка, градиент,
  фигуры, текст, пипетка.
- **Выделение:** прямоугольник, эллипс, лассо, прямолинейное лассо, волшебная палочка, цветовой диапазон;
  выделенное в новый документ, кадрирование по выделению.
- **Нарезка:** слайсы с 9-slice, сетка, авто по прозрачности, нож; экспорт слоёв и слайсов в отдельные
  файлы (PNG/JPG/WebP/TIFF, обрезка, @1x/@2x, ZIP, JSON).
- **Слои:** режимы наложения, маски, обтравочные маски, непрозрачность заливки, стили (тени, свечения,
  обводка, наложение цвета/градиента/узора).
- **Цвет и трансформации:** кривые, уровни, тон/насыщенность и др.; свободная трансформация, наклон,
  искажение, перспектива.
- **Рабочее место:** вкладки с перетаскиванием, сплит экрана, навигатор, линейки, направляющие, сетки,
  ограничение прокрутки краем картинки.
- **Форматы:** PSD (слои, маски, стили), TIFF, TGA, WebP (в WebKit — через Rust), PNG, JPG.
- **Спрайтшиты** (TexturePacker JSON, Phaser 3, Spine, Starling, Cocos2d, CSS, CSV, свои шаблоны) и
  **генератор BMFont** (градиент, эффекты, `.fnt`/JSON/сетка).
- **Имя:** проверены варианты, выбрано **PixelYard** (раньше — PhotoEdit; папка осталась `~/src/photoedit`).
- **Подписанные сборки:** `npm run release` — интерактивный инструмент «как в Expo»: организации Apple,
  ключи App Store Connect API, сертификат Developer ID, нотаризация, DMG, проверка Gatekeeper; оформлен
  как скилл `~/.claude/skills/apple-sign-release`. Грабли: Developer ID через API выпускает только
  Account Holder (403) — добавлен путь через CSR на сайте Apple.
- **GitHub:** README со скриншотами, описание репозитория, релиз v0.1.1.

## 0.1.2 — редактор атласов (30 октября)

Атлас — отдельный документ-проект `.pyard` (zip: `project.json`, PNG спрайтов, PSD-исходники).
Упаковщик MaxRects с пятью эвристиками, полками, сеткой и «наилучшим» перебором, вращение, несколько
страниц; клик/⇧/рамка по спрайтам, свойства выбранных (масштаб, обрезка, extrude, поворот, опорная
точка, 9-slice, папка); двойной клик — правка спрайта в связанной вкладке с живой перепаковкой;
анимации с превью; выгрузка в нескольких масштабах в PNG/WebP/JPEG; новые форматы Unity `.tpsheet` и
Godot `.tres`; WebP в BMFont; `.pyard` открывается из Finder. Подробный проект — `docs/design/atlas.md`.

Грабли: «наилучший» выбирал вытянутые страницы — высота подбирается от площади, штраф за вытянутость;
`pointerdown.detail` в Chrome всегда 0 — двойной клик ловится родным `dblclick`.
Выпуск: при выборе версии пользователь взял «исправления» → вышло 0.1.2 вместо 0.2.0.

## 0.2.0 — большой выпуск (30–31 октября)

Всё ниже — по просьбам пользователя, по одной-две за раз, с проверкой в браузере и в собранной программе.

- **Боковые панели в колонки** (`src/dock.ts`): панель тянется за заголовок в другую колонку или на «+»,
  ширина колонок, своя раскладка для картинок и атласов. Грабли: 11 кнопок «Слоёв» не влезали —
  колонка прокручивалась вбок и «всё ехало»; линию места вставки перекрывал фон заголовка.
- **Иконка приложения** (`core/icons.ts`): ICO с выбором размеров, ICNS (проверен `iconutil`),
  favicon + webmanifest, iOS, Android, Tauri/Electron, набор PNG.
- **PDF** (`core/pdf.ts`): импорт через pdf.js (одна страница / все слоями / все вкладками, dpi,
  подложка); экспорт — свой писатель (Flate + SMask), проверен pdf.js и CoreGraphics.
- **Папки слоёв и цветовые метки**, с сохранением в PSD.
- **Редактор 9-slice**: границы на холсте, живой предпросмотр растяжения, `.9.png`, PNG + JSON.
- **Растровые шрифты**: меню «Шрифт», библиотека (созданные и открытые `.fnt`), BMFont в «Тексте».
- **Текстовые слои как в Photoshop**: редактируемы до растрирования, правка повторным кликом,
  параметры применяются к слою, PSD с текстом. Грабли: фокус поля ввода в момент нажатия уводил браузер.
- **Выделение:** повторный клик снимает, Ctrl вычитает; палочка смотрела на активный слой (отсюда
  «не то» выделение) — теперь по видимому изображению, сравнение с учётом прозрачности, допуск
  протягиванием.
- **Скорость на больших документах:** курсор тормозил, потому что каждое движение мыши пересводило все
  слои и заливало весь документ в видеокарту (`willReadFrequently`). Сейчас: кэш сведения, кэш подложки,
  копия в видеопамяти, уровни уменьшения, кэш эффектов по версии пикселей слоя — кадр ~0,3 мс вместо ~50.
- **Системное меню macOS** (`src/nativeMenu.ts`) из того же описания `MENUS`; «текстовые» сочетания
  (⌘C/V/Z/A, ⌫) не привязаны к меню, чтобы работали в полях ввода.
- **⇧ при перетаскивании файлов** — новыми вкладками (модификаторы спрашиваются у macOS из Rust).
- **Новый документ из буфера обмена** с превью и размером.
- **Печать (⌘P)** как в Photoshop: лист, поля, картинку двигать/масштабировать, подогнать, метки обреза
  и приводки; системный диалог печати (`webview.print`) или PDF листа.
- **Цвет:** диалог «Палитра цветов» (канал на полосе, HSB/RGB/Lab/CMYK/HSL/HEX, пипетка), круг гармоний
  (триада треугольником и др.), свои палитры с `.gpl`. Грабли: при дробном dpr круг рисовался пустым.
- **Штамп (S)** и **стрелка** с изгибом кривой Безье в «Фигурах».
- **Сканирование** (`src-tauri/src/scanner.rs`, ImageCaptureCore): МФУ пользователя — HP LaserJet MFP
  M234dw по сети (планшет, 200/300/600 dpi). Область вырезается у нас из скана всего стекла.
  Грабли: без делегата `ICDeviceBrowser` список устройств пуст — проверено `examples/scan_probe.rs`.
- **Вопрос о несохранённом при любом выходе** (⌘Q, Dock, окно) — раньше ⌘Q закрывал молча.
- **Сохранить как** с выбором формата и качества; **Экспортировать как** (⌥⇧⌘W) с предпросмотром.
- Выпуск 0.2.0 сделан агентом целиком (`npm run release -- --yes`): сборка, подпись, нотаризация, GitHub.

## Как теперь работаем

- Правка → проверка в браузере (`npm run dev`, Chrome, `window.__pe`) → `tsc` + `vite build` →
  коммит на русском → push в `main`.
- Перед каждой сборкой для установки — поднять версию (patch) и раздел в CHANGELOG.
- Локальная установка: `npx tauri build --bundles app` и замена `/Applications/PixelYard.app`
  (программу закрывать — она сама спросит о несохранённом; если открыта старая версия без вопроса —
  просить пользователя закрыть самому).
- Выпуск: поднять версию в `package.json` и `src-tauri/Cargo.toml`, раздел версии с датой в
  CHANGELOG, коммит и push, затем `npm run release -- --yes`. Пока релиз идёт — ничего не коммитить:
  инструмент сам пушит HEAD и ставит на него тег.
