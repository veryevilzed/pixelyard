# PixelYard

Десктопный редактор изображений для macOS, чтобы готовить игровые и UI-ресурсы:
поправить картинку, нарезать на части, разложить по слоям и выгрузить каждый
кусок отдельным файлом.

Стек: **Tauri 2** (Rust) + **React 19** + **TypeScript** + Canvas 2D.

## Запуск

```sh
npm install
npm run app:dev      # окно приложения с горячей перезагрузкой
npm run app:build    # src-tauri/target/release/bundle/macos/PixelYard.app и .dmg
npm run dev          # только веб-интерфейс в браузере (http://localhost:1420)
```

Нужны Node 20+ и Rust (`rustup`).

## Релиз: подписанная сборка

```sh
npm run release              # спросит всё по шагам
npm run release -- --yes     # с сохранёнными ответами (секреты всё равно спросит)
npm run release -- --dry-run # только показать план и команды
```

Инструмент проходит по шагам:

1. Проверяет окружение (Rust, Xcode Command Line Tools, notarytool).
2. Повышает версию (patch/minor/major или вручную) в `package.json` и `Cargo.toml`.
3. Спрашивает название, Bundle ID, копирайт и минимальную macOS.
4. Предлагает архитектуру: Apple Silicon, Intel или Universal.
5. Подписывает сертификатом из связки ключей (Developer ID Application). Если его
   нет, предложит импортировать `.p12`.
6. Нотаризует одним из способов: профиль `notarytool` в связке ключей
   (рекомендуется), Apple ID с паролем приложения или ключ App Store Connect API.
7. Собирает, подписывает `.app`, нотаризует и прикрепляет тикет. Потом собирает
   `.dmg` из нотаризованного приложения и тоже подписывает, нотаризует и
   прикрепляет тикет.
8. Проверяет подпись и Gatekeeper, пишет `SHA256SUMS`, по желанию ставит git-тег.

Результат кладётся в `release/<версия>/`. Ответы без секретов сохраняются в
`.release.json` (он в `.gitignore`); пароли и ключи не сохраняются нигде, кроме
связки ключей macOS. В браузерном режиме вместо диалогов
открываются `<input type=file>` и скачивания; запись прямо в папку работает
только в приложении.

## Возможности

**Форматы.** Открывает PNG, JPG, WebP, GIF, BMP, ICO, SVG, HEIC, TIFF
(многостраничный — по слою на страницу), TGA, PSD (слои, режимы, маски,
обтравка, стили слоя). Сохраняет в PSD со всем перечисленным, а также в PNG,
JPG, WebP (кодирует Rust) и TIFF.

**Инструменты** (слева): перемещение, прямоугольное и овальное выделение,
лассо, прямолинейное лассо, волшебная палочка, рамка (кроп), раскройка
(слайсы), нож (раскрой линиями), пипетка, кисть (жёсткость, интервал,
сглаживание, нажим пера), карандаш (попиксельно, pixel perfect), ластик
(мягкий или попиксельный), заливка (цвет или узор), градиент, фигуры, текст,
рука, масштаб.

**Слои.** Режимы наложения, непрозрачность и отдельно непрозрачность заливки,
обтравочные маски (⌥⌘G), маски слоя (чёрный скрывает, белый показывает),
стили слоя: тень, внутренняя тень, внешнее и внутреннее свечение, наложение
цвета, градиента и узора, обводка.

**Выделение.** Режимы добавить, вычесть и пересечь; цветовой диапазон
(⌥⌘O); расширить, сжать, граница, растушёвка; выделенное в новый документ
(⌥⌘N), кадрирование по выделению (⌥⌘X), новый слой из выделенного (⌘J).

**Нарезка.** Сеткой (по количеству или размеру ячейки), автоматически по
прозрачности, ручные слайсы, 9-slice, нож (резы мышью, с шагом или по
направляющим), куски в слои или слайсы.

**Экспорт** (⇧⌘E): слои, слайсы или всё изображение; обрезка по содержимому,
поля, масштабы @1x/@2x/…, JSON с координатами. Вывод в папку, в ZIP или в
атлас-спрайтшит с JSON в формате TexturePacker Hash.

**Вид.** Линейки (⌘R), направляющие (тянутся из линеек), сетка, пиксельная
сетка от 800%, привязка к сетке, направляющим и краям.

Полный список горячих клавиш: «Справка → Горячие клавиши» (⌘/).
